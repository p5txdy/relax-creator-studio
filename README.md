# 漫画推文

本地运行的 AI 漫画推文制作工具。当前正式版本：`v1.1`。

## 业务流程

应用采用“建立人物场景项 → 新建并关联推文项目 → 小说与项目 → 角色定妆 → 场景定景 → 分镜编排 → 批量出图 → 剪映草稿”的流程。

- 主页显示全部漫画推文项目，每个项目独立保存小说、分镜、图片、音频、字幕和成片。
- 制作新推文前必须先建立项目，可在主页随时切换或删除项目记录。
- 旧版单项目数据首次打开时会自动迁移为一个漫画推文项目。
- 人物与场景放在同一个“人物场景项”中，可按系列小说、账号或世界观建立多个项。
- 创建推文项目时可关联已有项或同时新建项；关联后自动带出该项全部人物和场景，项目中新增、修改或确认的资产也自动写回该项。
- 新建推文默认创建独立空白项，不带入任何其他项目图片；只有在下拉框中主动选择已有项时才共享素材。
- 新建项目弹窗始终显示新项名称输入框；已有项可在“小说与项目”页面的关联栏中直接重命名。
- 主页“人物场景项管理”可查看每个项的资产和关联任务数量，并删除不再需要的项；工作台关联栏也可直接删除当前项。删除项会永久移除其中的人物、场景、候选图和固定参考图；仍关联的任务会转入新的空白项，小说与分镜原文不会删除。
- 关联同一项的多个推文项目实时共用人物、场景、提示词和参考图；不同项彼此隔离，不会串人物或场景。
- 旧版全局人物和场景会自动迁移到“默认人物场景项”，参考图复制到该项自己的本地素材目录。
- 固定人物与场景参考图保存在本地；只有明确确认永久删除时才会删除标准素材目录内的文件。
- 人物和场景可导出为 ZIP 资产包，在另一台电脑导入后会复制图片并重建本地路径。

## AI 分析与防遗漏

- 可分别执行“只识别角色”“只识别场景”“只生成分镜”，也可一次生成角色、场景与分镜。
- 不需要设置每个片段的字数；AI 会根据场景变化、动作、对白和情绪转折自动决定分镜边界。
- 分镜采用静态漫逻辑：一个分镜只表现一个可定格的关键瞬间；对白换人、人物反应、姿态变化、动作发生与结果会优先拆成不同图片。
- 生图提示词禁止推拉摇移、跟拍、环绕、变焦、转场等动态运镜，也禁止把连续动作、多时间点、分格或连环画塞进一张图片。
- 镜头画面提示词只保留“人物 + 一个表情或动作”的短句；提交生图时仅补充角色/场景参考图、画风、静态单幅和画幅要求。
- 程序仅按技术上限把长文本分批发送，避免上下文过长；AI 返回后会校验所有分镜原文是否按顺序完整覆盖输入正文。
- 请求连续失败时会自动缩成更小的文本批次继续处理；残缺或改写原文的结果不会覆盖已有分镜。

## 角色、场景与生图

- 角色和场景均支持生成候选图、预览、确认保留或导入现有参考图；候选图和已确认参考图会直接显示在编辑区。
- 项内人物或场景改名、删除会同步更新所有关联该项的推文分镜；删除单个推文项目不会删除人物场景项及其参考图。
- 人物参考图提示词强制要求单人全身定妆和纯色无缝背景，并排除场景、建筑、家具、环境道具和其他人物。
- 每个分镜可多选角色并单选一个固定场景。
- 静态分镜页可对全部分镜或多选分镜批量替换/移除角色、批量替换/清空场景；修改绑定后会将相关图片标记为待重新生成。
- 镜头清单支持普通单击切换多选，不需要按住 Ctrl，并提供“全选镜头”和“清空选择”。
- 静态分镜页的每个镜头行都直接显示自己的图片、原文、画面提示词、角色、场景和状态；提示词可在对应行编辑、失焦自动保存，也可点击该行的保存按钮。
- 每个镜头行中的角色可普通点击直接多选，场景使用常驻的单选列表直接改选；修改会立即保存，已出图镜头会同步标记为待重新生成。
- 静态分镜的表头和每个镜头行共用同一组七列宽度，选择、画面、原文、提示词、角色、场景与状态上下严格对齐。
- 静态分镜采用扁平表格布局：移除重复外层卡片和行内多层卡片，提示词、角色、场景直接位于同一镜头行中，只保留必要的滚动条和选择状态。
- 人物与场景替换区固定显示在分镜列表上方，无需先点击某个镜头；可作用于全部分镜或跨页保留的已选分镜。
- 大型项目每页显示 12 个镜头并保留独立滚动条，避免一百多个提示词编辑器同时加载造成卡顿。
- 支持人工合并两个相邻镜头，以及在原文中点击精确位置把一个镜头拆成两个；这些操作只调整当前镜头，不会整批重做或重新调用 AI。
- 角色或场景改名会自动保存并实时同步到镜头清单，不再保留失效的旧名称。
- 角色定妆提示词自动持久化，并支持当前角色提示词的 TXT/Markdown 导入和 TXT 导出。
- 使用 Doubao Seedream 5.0 Pro 出图，同时提交确认后的角色和场景本地参考图。
- 批量分镜可通过 Lite / Pro 双按钮直接切换生图模型；Lite 使用 `doubao-seedream-5-0-lite-260128`，高质量模型使用官方 ID `doubao-seedream-5-0-260128`。
- 批量出图支持普通单击连续多选镜头，并只重新绘制选中项；已有图片仅在新图成功下载后替换。
- 分镜构图以中近景和近景为主，人物优先胸像、半身或腰部以上并占据画面主体；仅在剧情必须交代环境时使用中景，不使用远景或大全景。
- 批量出图的输出分辨率改为可直接点击的常驻按钮，选择后立即保存到当前项目；Lite 提供 2K/3K，Pro 提供 1K/2K/3K/4K。Pro 的 1K 会按照项目画幅转换为满足接口最低 3,686,400 像素要求的明确宽高，其余预设自动转为小写格式。
- 批量出图页新增项目封面制作：可填写封面标题和画面提示词，选择已确认人物与固定场景作为参考；每次固定生成 3:4 两张和 4:3 两张不同构图，标题位于画面水平居中、垂直中间偏下，四张结果按项目保存并可逐张预览。
- 性能优化：批量出图只按当前可见区域渐进加载缩略图，静态分镜每页显示 12 条；圆角控件与图片缩略图会复用缓存，滚动条不再反复生成高分辨率抗锯齿图片，连续编辑会合并保存并限制备份频率。
- 角色与场景参考图合计最多 10 张；绑定资产缺少本地参考图时会在调用 API 前提示。
- 场景提示词会在生成前强制沿用当前项目画风，确保场景定景与角色定妆保持同一种视觉风格；旧提示词和手动提示词也会自动补齐该约束。
- 批量出图页按分镜逐行显示“对应图片、片段、角色、场景和状态”，图片不再集中混排；点击该行缩略图即可放大、缩小和拖动画面检查细节。

## 静态漫剪映草稿

- 可导入配音和 SRT 字幕；字幕素材卡使用独立的大尺寸导入区，便于查看文件状态和重新选择字幕。
- 使用每个分镜保存的原文与 SRT 逐字对齐，让图片切换点对应实际剧情；没有字幕时按分镜原文长度分配时长。
- 直接生成真正的剪映本地草稿，不会先把图片压制为 MP4。
- 默认使用“抖音漫画推文效果”：每张分镜固定轻微放大，只添加向上或向下缓慢平移的两个位置关键帧，镜头按字幕节奏直接切换。
- 成片效果与图片画风解耦；韩漫、日漫、国漫等画风都复用同一套静态漫剪辑规则，不生成人物动作或动态漫画。
- 配音和 SRT 字幕分别写入可编辑轨道；字幕默认为黄色粗体黑描边并位于画面下部安全区，生成页面会显示逐步百分比进度。
- 可选择“生成并打开剪映”，也可稍后重新打开已有草稿或草稿目录。

## AI 小说改文

- 侧栏“AI 小说改文”支持导入 TXT、Markdown、DOCX，或直接粘贴正文。
- 自动拆章并保留原文对照，可单章改写或批量改写。
- 默认使用“短视频悬念解说（推荐）”：将小说改成可直接配音的解说稿，前两句抛出真实冲突，中段持续增加有效信息、升级危机并压缩无效铺垫，结尾停在原文已有的悬念钩子上；禁止捏造人物、事件或虚假反转。
- 支持改写模式、目标风格、叙事视角、篇幅、自定义规则和人物世界观设定库。
- 改写结果可人工调整并导出为 TXT。

## Windows 运行

### 使用打包好的程序

从 GitHub Actions 下载 Windows 压缩包，解压后直接运行：

```text
漫画推文-v1.1.exe
```

也可以双击仓库根目录下的 `启动漫画推文.cmd`：存在正式 EXE 时直接打开；没有 EXE 时会转入源码运行器并在首次启动时自动建立独立环境、安装依赖。

### 从源码运行

安装 64 位 Python 3.12，在 PowerShell 中进入仓库目录后执行：

```powershell
py -3.12 -m venv .venv-windows
.\.venv-windows\Scripts\python.exe -m pip install --upgrade pip
.\.venv-windows\Scripts\python.exe -m pip install -r requirements-windows.txt
.\.venv-windows\Scripts\python.exe .\app.py
```

也可以直接双击 `启动Windows开发版.cmd`，首次运行会自动创建 `.venv-windows` 并安装依赖。需要生成单文件 EXE 时，双击 `打包Windows版.cmd`，产物位于 `dist\漫画推文-v1.1.exe`。

本地状态保存在 `%APPDATA%\ComicPostStudio\state.json`，最近 20 份历史位于同目录的 `backups` 文件夹。首次运行会从旧版 `RelaxCreatorStudio` 目录迁移状态，并扫描仍存在的角色/场景图片恢复索引。程序使用单实例锁，避免多个窗口互相覆盖。API Key 不写入状态文件，启用安全记住后保存在 Windows 凭据管理器。

## macOS 运行

Windows 的 EXE 不能直接在 Mac 上运行。macOS 版本必须在 Mac 本机生成；同一套源码同时支持 Apple 芯片和 Intel Mac，PyInstaller 会按当前 Mac 的处理器架构构建应用。

### 一键生成 Mac 应用

1. 安装 [Python 3.12](https://www.python.org/downloads/macos/) 和 [Homebrew](https://brew.sh/)。
2. 在终端进入仓库目录，执行 `chmod +x 启动漫画推文-Mac.command 启动Mac开发版.command 打包Mac版.command`。
3. 双击 `打包Mac版.command`，或在终端运行 `./打包Mac版.command`。
4. 脚本会安装 `libmediainfo`、FFmpeg 和 Python 依赖，随后生成：
   - `dist-macos/漫画推文-v1.1.app`
   - `dist-macos/漫画推文-v1.1-macOS.dmg`
5. 双击 DMG，把应用拖入“应用程序”。首次启动时在 Finder 中右键应用并选择“打开”。

### 从源码直接运行

不打包时可在终端执行：

```bash
brew install libmediainfo ffmpeg
python3 -m venv .venv-macos
source .venv-macos/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements-macos.txt
python app.py
```

普通使用可直接双击 `启动漫画推文-Mac.command`：已构建 `.app` 时直接打开应用，否则转入源码运行器。也可直接双击 `启动Mac开发版.command`，首次运行会自动创建 `.venv-macos`、安装依赖并启动源码。

macOS 状态保存在 `~/Library/Application Support/ComicPostStudio/state.json`，API Key 启用安全记住后保存在系统钥匙串。应用已内置 MediaInfo；生成剪映草稿不要求安装 Python 或 Homebrew。可选 MP4 预览需要另外安装 FFmpeg，或在“模型与工具”中指定现有的 FFmpeg。

Mac 打包脚本会执行 MediaInfo 实际解析和剪映草稿写出自检。由于当前应用使用本机临时签名而非 Apple 开发者公证，首次运行仍需使用 Finder 右键“打开”。

### GitHub 自动生成双平台安装包

仓库的 `Build Windows and macOS` 工作流会分别构建 Windows x64 EXE、macOS Apple Silicon DMG 和 macOS Intel DMG。打开仓库的 `Actions` 页面，进入一次成功的运行记录，即可在 `Artifacts` 中下载对应系统的压缩包；无需把本地生成目录提交进源码仓库。

## 配置模型

“模型与 API”页面可配置 DeepSeek、千问、智谱 GLM、Kimi、OpenAI 或其他 Chat Completions 兼容服务，用于角色、场景和分镜分析。

进入任意漫画项目后，点击右上角“Seedream API”配置火山方舟地址、模型 ID 与 ARK API Key。Seedream 5.0 高质量模型使用官方 ID `doubao-seedream-5-0-260128`；批量出图页也可直接切换 Lite / Pro。

静态漫草稿需要剪映专业版及其本地草稿目录；程序会自动检测，也可在“模型与工具”中手动选择。FFmpeg/FFprobe 仅用于可选的 MP4 预览和媒体时长回退。

## 测试与打包

```powershell
python -m unittest discover -s tests -v
.\打包Windows版.cmd
```

Windows 单文件产物位于 `dist\漫画推文-v1.1.exe`。
